# E-commerce SID-2 search matrix

> **Note:** This report was generated by an LLM.

## Summary

This experiment compares BM25, GPT-5 and GPT-5-mini search agents, and SID-2
agents using low, medium, or high reasoning. The agent variants use BM25 alone
or BM25 with E5-base-v2. Results cover all 480 WANDS queries and a 1,000-query
ESCI sample, with seed 42.

SID-2's best WANDS result is BM25 with high reasoning (mean NDCG 0.6156), close
to GPT-5 with BM25 (0.6214). The SID-2 high-reasoning run used 8.719 mean tool
calls per query versus 6.365 for GPT-5. On ESCI, the best SID-2 result is BM25
with E5 and low reasoning (0.4253 NDCG, 2.131 tool calls); GPT-5 with BM25 and
E5 reaches the highest score overall (0.4537).

E5 raises the low-reasoning score from 0.4087 to 0.4253, with mean tool calls

low-reasoning scores.

variant, with each row's run commit SHA.

## Configuration and reproduction

The six SID configurations use `sid/sid-2` with reasoning effort `low`,
`medium`, or `high`, and either BM25 or BM25 plus E5-base-v2:
[`configs/ecom_sid/`](../../configs/ecom_sid/). Baselines are configured in
[`configs/ecom_base/`](../../configs/ecom_base/),
[`configs/agentic_ecom_bm25_gpt5.yml`](../../configs/agentic_ecom_bm25_gpt5.yml),
and [`configs/ecom_agentic/`](../../configs/ecom_agentic/).

The machine-readable results are in
[`research/results/ecom_sid_matrix.csv`](../results/ecom_sid_matrix.csv).
The runner uses eight workers by default, seed 42, all WANDS queries, and a
1,000-query ESCI sample. To regenerate the four graphs from the existing CSV
without running models:

```bash
uv run python scripts/plot_ecom_sid_matrix.py \
  --input research/results/ecom_sid_matrix.csv \
  --output-prefix assets/ecom_sid_matrix
```

To refresh just the SID results, preserving non-SID rows and bypassing the SID
result cache:

```bash
RERUN_SID_VARIANTS=true ./scripts/run_ecom_sid_matrix.sh
```

The runner writes the refreshed CSV and regenerates all four graphs. Running the
full matrix also runs the GPT-5 and GPT-5-mini variants. Set
`RERUN_SID_VARIANTS=false` in the script before that run and remove any later
local override of the flag. `NO_CACHE=true` bypasses the result cache for all
selected variants and can incur new OpenAI API usage.
